# toon-healing-game

웹 기반 3D 카툰 렌더링 힐링 게임 프로젝트입니다.

## 개요

- **장르**: 힐링 / 탐험 기반 3D 웹 게임
- **분위기**: 카툰/셀 셰이딩, 밝고 따뜻한 색감
- **플랫폼**: 웹 브라우저

## 기술 스택 (계획)

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [React Three Fiber](https://docs.pmndrs.com/react-three-fiber)
- [Three.js](https://threejs.org/)
- TypeScript

## 현재 상태

초기 리포지토리 설정 단계입니다.  
소스코드는 아직 추가되지 않았으며, 추후 개발을 진행할 예정입니다.
